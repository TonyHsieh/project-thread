what is a token? it is the smallest unit that an AI parseer breaks down a corpus of text or whatever the Ai is accepting as input.  This is also used as way to meter the amount compute is being accepted for AI billing purposes.
an embedding? The assiging a vector value to a token representing the trained value by an LLM so that tokens representing a similiar concept is grouped together.
attention? This is the process of assigning values of related words to each other in a particular input group which enhances the convey blended and contextual meaning.
a gradient? This is the rate of change for any attribute in any direction in an attribute vector.  It is important to what understand what changes when one or some incoming weights are changed but all of the others held fixed.  
a loss function? This is the way to "penalize" the model when it achieves the wrong goal. 
temperature? This is the value that is set to introduce non-determinism to the LLM.  The higher (or hotter temperature) the more likely it will pick a less "likely" next token... the lower (or cooler temperature) the most likely it will be the most likely next token.
fine-tuning vs prompting? fine-tuning is a permanent adjusting of the LLM output to answer in a tuner's desired way.  Prompting is only during the live working session and context window.
RAG? Retrieval Augmented Generation is the process of running any AI request through an addition body of context (usually something knowledge domain specific) which returns generated answers which incorporate input from that additional body of context without having to spend money, time and effort to fine-tune or retain an LLM to use the domain specific information.
an agent? An autonomous independent worker with a particular section of work to work on but it is managed by an overseer (another AI or a human)
