Contract Invariants Enforced

  • One-Module-One-Job: textgen.py is strictly a stateless model boundary. It never executes tools or accesses file systems.
  • The Model Proposes; Code Disposes: Tool invocations are untrusted. call_tool validates schemas, isolates crashes (ok = False), and the agent feeds errors back so the model can self-correct.
  • Generic Source Collection: The agent loop never branches on tool names (like search_corpus); it inspects types (SearchResult).
  • Migration (v3.8) Correlation: call_uid is strictly preserved across ToolCall.call_uid == ToolResult.call_uid == Message.call_uid.
  • The Null Rule: Unknown token metrics and unpriced costs are None, never 0 or fabricated.
  • Step Definition: AgentResult.steps measures model decision rounds (generation calls), not individual tool count.
